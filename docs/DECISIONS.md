# Decisions log

One line per decision, with the rationale. Newest at the bottom.

| # | Date | Decision | Rationale |
|---|------|----------|-----------|
| 1 | 2026-11-08 | Existing scraper files (`api/app/scraper/**`) are exempt from the 200-line and no-inline-comment rules and are not refactored. | The scraper contract requires identical behavior; splitting `parser.py` (280 lines) or `default.py` (416 lines) would be a rewrite of working code with no functional gain. New code follows the conventions. |
| 2 | 2026-11-08 | Lint/typecheck tooling (ruff, mypy) excludes `api/app/scraper/**`. | Same reason as #1: the scraper is frozen by the parity test, so style tooling must not force edits into it. |
| 3 | 2026-11-08 | Local Python 3.11 is provided through `uv` (`make install` creates `api/.venv` with Python 3.11). | The host only ships Python 3.14, which the pinned `pydantic==2.5.3` / `lxml==4.9.4` / `playwright==1.41.0` do not support; the Docker image already uses 3.11, so local and container runtimes now match. |
| 4 | 2026-11-08 | Captcha / robot detection is not added to the scraper output; the seed script detects blocked pages (no title, or a title/description matching captcha markers) and falls back to the PDF data. | The output schema is frozen by the contract; the current code has no explicit captcha field, so detection lives in the consumer. |
| 5 | 2026-11-08 | The owner role is assigned at registration time to the account whose e-mail equals `OWNER_EMAIL`; changing the variable later does not demote the existing owner. | Simplest rule that needs no admin UI; a second owner would only appear if the variable is changed and a new account registers with the new address, which the deployer controls. |
| 6 | 2026-11-08 | Anonymous visitors see every gift as available; reservation status is only returned to authenticated non-owner accounts. | The owner could otherwise open the public page in a private window and learn what is reserved; requiring a login for availability keeps the API the single point of enforcement. |
| 7 | 2026-11-08 | `POST /api/scrape` keeps its request/response contract but now requires the owner token, validates the target URL against private/internal addresses, is rate limited, cached for 5 minutes and bounded by `SCRAPE_TIMEOUT_SECONDS`. | A public scraping endpoint on a free host is an abuse and SSRF vector; the brief asks for an owner-only endpoint and allows these hardening measures. |
| 8 | 2026-11-08 | The Next.js frontend keeps the JWT in `localStorage` and sends it as a Bearer header. | Frontend (Vercel) and API (another host) live on different origins; cross-site cookies would need `SameSite=None` and a shared domain. Tokens expire after 7 days. |
| 9 | 2026-11-08 | Seed rule: the scraped price wins only when the scraper returns both a price and a 3-letter currency; otherwise the PDF price in EUR is used and the gift is flagged (`pdf_price`, `pdf_price_currency_unknown`). A page counts as blocked when it has no title or an error-page title ("Oops! Something went wrong", robot/captcha) without a price. | amazon.com pages return a price without a currency; storing "8.97 EUR" would be wrong, and the brief says the PDF price is the fallback. |
| 10 | 2026-11-08 | Seed images: the scraped first image is used, except for the AliExpress keyboard (the scraped picture shows the black/grey "Dolch" variant while the PDF shows the white variant) and for blocked pages, which use the image extracted from the PDF and served from `frontend/public/seed/`. | The brief makes the PDF image the reference for the exact AliExpress variant. |
| 11 | 2026-11-08 | Seed gifts keep the brief's URL as `purchase_url` and are upserted by that URL, so re-running the seed updates prices and images instead of duplicating gifts. | Idempotent seeding for local, CI and production. |
| 12 | 2026-11-08 | A visitor's own reservation stays listed in "Mes réservations" even if the owner later hides the gift, so the visitor can still cancel it. | Hiding is an owner-side presentation choice; silently dropping a reservation would surprise the visitor. |
